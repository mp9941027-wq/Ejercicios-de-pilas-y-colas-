 Ejercicios de Colas en Java 

Colección de ejercicios resueltos sobre el uso de **colas (Queue)** en Java,
implementados con `java.util.Queue` y `LinkedList`. El proyecto simula tres
escenarios reales: atención de clientes con tickets, procesamiento de pedidos
logísticos y una cola de impresión.

Objetivos
- Aplicar el TAD **Cola (FIFO)** en problemas reales.
- Practicar operaciones `offer`, `poll`, `peek` e iteración sin eliminar.
- Modelar entidades con clases (`Cliente`, `Pedido`, `Impresion`).
